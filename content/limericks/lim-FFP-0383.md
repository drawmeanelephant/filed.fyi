# FFP-0383 Exhibit: Metrics of Systemic Decay

## Archival Verses


A null in the hash of the core,  
Led users to save evermore.  
The icon flashed bright,  
With meaningless light,  
And ruined the database floor.  



The dashboard is brightly designed,  
With buttons that click and unbind.  
The data is lost,  
We waive any cost,  
And leave the old server behind.  



The hash on the floor is erased,
Where meaningful fields were displaced.
The icon will flash,
While hiding the crash,
And waiting for forms to be spaced.
