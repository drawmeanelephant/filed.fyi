# Replacement Without Release Routing Note


The shelf we assigned is quite small,  
With no public routing at all.  
The structure is new,  
But the old gear is due,  
So the links must not echo or crawl.  



We placed it by Managed Absence,  
Assuming a similar tense.  
The labels agree,  
With the Trust Surface tree,  
Though the grouping makes zero real sense.  



The interval welcomed the new,  
While serving the old system too.  
The upgrade was cast,  
But the old codes hold fast,  
So the interim phase just outgrew.  



A hub-level link was deployed,  
Which made the department annoyed.  
The routing was broad,  
So we called in the squad,  
And the reference file was destroyed.
