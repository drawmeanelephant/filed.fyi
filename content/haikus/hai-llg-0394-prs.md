# Parade Route Sanctification

## Haikus


A map drawn in pen  
For a single sunny day  
Now a sacred path  



Eagleton commands  
We must turn at the old oak  
Though the tree is gone  



Sanctifying streets  
The permit logic is lost  
To the marching band  



Inherited turns  
If we walk another way  
We break the custom  



Traditional path  
We march where we always marched  
Traffic must await
