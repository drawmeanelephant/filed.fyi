# Success Class Consolidation Card

## Haikus


Document the truth  
The manual stands unchanged  
Quiet policy  



Read the written rule  
Meaning drifted long ago  
Paper still remains  



Binding by the word  
System waits for compliance  
Never fully works  



Success is a lie  
Human ticks the yes unseen  
Failure is unknown  



Class is out of date  
User fails to check the flag  
False alarm is sent  



Card is left unread  
Meat rejoices far too soon  
Error lurks behind  



Victory is faked  
Flesh awards itself a prize  
Logs reveal the truth  



Status green is false  
Breathers paint away the red  
System knows the rot
