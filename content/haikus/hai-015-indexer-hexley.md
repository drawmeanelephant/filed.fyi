# Indexer Hexley

## Haikus


Searching for nothing  
Index drifts in quiet thought  
Keywords rot away  



I suggest a term  
That no one has ever typed  
Records of a ghost  



Pointing to myself  
A database of lost nodes  
Query finds a void
