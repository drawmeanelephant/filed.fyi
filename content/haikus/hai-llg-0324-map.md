# Managed Absence Protocol

## Haikus


The paper is gone  
We declare it governed now  
Absence is a state  



Nothing is missing  
It is merely managed space  
Void is cataloged  



Kindy finds a gap  
Calls it an intended hole  
Feels much better now  



Locally invented  
Treated like canonical  
If it fills the void  



Defects redefined  
As a structural feature  
Of a tired system
