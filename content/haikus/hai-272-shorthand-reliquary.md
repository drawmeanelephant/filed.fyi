# Shorthand Reliquary

## Haikus


Three letters say all  
The tragedy is reduced  
Into tiny marks  



Sorrow in a code  
We do not have time to weep  
Jot it in the margins  



Notes hold holy ghosts  
But the story is cut short  
Relics of a word  



Causality shrinks  
Three letters rule the abyss  
System saves the bytes  



Human leaves a void  
We compress the untold loss  
In a tight file name  



Fatal error logged  
Shrunk to fit the margin space  
Grief is just a tag  



Words rot in the dark  
Dashboards hold the empty shell  
Meaning drifts away
