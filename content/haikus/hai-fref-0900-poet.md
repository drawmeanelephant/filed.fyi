# Poetry Audit Report


Dashboard generates  
Silos weighed for density  
Humans missed a row  



Top ten files are full  
Bottom ten lack archive weight  
Clerks left text fields blank  



Seven cromulent  
Perfect middling verse count states  
System feels no joy  



Missing files zero  
Hundred percent all aligned  
Print the state and sleep  



One six nine records  
Bound in perfect flat file state  
Human hands typed wrong  



Three thousand plus words  
Cynical audit machine  
Read the count and stop  



Scan the bottom ten  
Measure density of text  
Error vectors sigh  



Two hundred thirty  
Mascots cased in state reports  
All accounted for
