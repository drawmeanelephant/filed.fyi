# Adjacent Correctness

## Haikus


Document the truth  
The manual stands unchanged  
Quiet policy



Read the written rule  
Meaning drifted long ago  
Paper still remains



Binding by the word  
System waits for compliance  
Never fully works




Almost perfectly  
The alignment missed the mark  
Call it a success  



Proximity counts  
We are adjacent to truth  
Error is ignored  



Close enough to right  
Human failure is the norm  
System will allow  



Shift the baseline down  
Now the failures look like wins  
Save the quiet log  



Correctness is a myth  
We adjust the definitions  
Flat file understands
