# Tier Whisper

## Haikus


You are level one  
The secrets are kept above  
Whispers in the cloud  



We care for the top  
The acoustics mute the base  
Priority talks  



Tiered voices are low  
VIPs get all the noise  
Silence for the rest  



User speaks too loud  
We unplug the lower tier  
VIPs just sigh  



Human leaves a note  
Fails the system access check  
Sunk in quiet depths  



Priority speaks  
But only to chosen nodes  
Baseline gets the buzz  



Errors from the top  
Whisper in a gentle tone  
Bottom tier just screams
