# Compassion Surfaces


Logged your pain in green  
Noted in the system log  
Filed without review  



Font is soft and round  
Colors soothe the weeping eyes  
Matrix bears no change  



User claims fatigue  
Parsed as weakness in the text  
Grant is thus withheld  



Empathy goes up  
Check-ins happen twice a day  
Rest is not approved  



Please describe your grief  
Form has ninety field drop-downs  
Subject bears the load  



Tone is very mild  
Sir we cannot help you now  
Queue will now reset  



Prompt has soft aspects  
Warmness in the interface  
Does not yield relief  



Humans trust the screen  
Think the interface is kind  
Cold flat file remains
