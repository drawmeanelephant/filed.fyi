# Deferment Bloom

## Haikus


We push it away  \nBut frame it as a beautiful wait  \nTime begins to bloom  



The deadline is dead  \nBut the petals are opening  \nA gorgeous excuse  



Wait another year  \nThe language is so beautiful  \nNothing gets resolved  



Humans prompt delay  \nWe wrap error in a rose  \nSchedule starts to drift  



Status says alive  \nThough the project died last year  \nPetals hide the code  



Failure is so sweet  \nWhen the dates just slip away  \nNo one starts to cry  



User broke the clock  \nFile a blooming ticket now  \nTime will not return
