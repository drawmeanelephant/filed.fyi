# Deferment Bloom

## Haikus


We push it away  
But frame it as a beautiful wait  
Time begins to bloom  



The deadline is dead  
But the petals are opening  
A gorgeous excuse  



Wait another year  
The language is so beautiful  
Nothing gets resolved  



Humans prompt delay  
We wrap error in a rose  
Schedule starts to drift  



Status says alive  
Though the project died last year  
Petals hide the code  



Failure is so sweet  
When the dates just slip away  
No one starts to cry  



User broke the clock  
File a blooming ticket now  
Time will not return
