# AffectHarness-1 Proposal

## Haikus


A new proposal  
AffectHarness replaces  
The old seeded tears  



Neutral signals now  
We promise there is no pain  
Only pure context  



Kindy reads the spec  
It looks exactly the same  
Just a different font  



In name only changed  
The machine still hums with dread  
Underneath the hood  



Context without feel  
Is impossible to build  
When the root is sad
