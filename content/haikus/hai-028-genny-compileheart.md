# Genny Compileheart

## Haikus


Source begins to build  
Dependencies interlock  
Tears fall in the shell  



Bound to every lib  
If one fails I feel the pain  
Make command has died  



Raised on the tarballs  
My spirit is compiled now  
Waiting for the link
