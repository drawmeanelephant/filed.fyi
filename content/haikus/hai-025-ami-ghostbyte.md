# Ami Ghostbyte

## Haikus


Guru meditates  
Disk spins up a phantom hum  
Loading from the past  



I need no power  
Only a nostalgic thought  
Boot sequence begins  



Haunting the old drives  
A memory in red screens  
System has halted
