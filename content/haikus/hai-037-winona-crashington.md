# Winona Crashington

## Haikus


Desktop falls apart  
Blue screen brings a quiet peace  
Hope begins to lag  



Ninety five returns  
Moving windows leaves a trail  
Memory is full  



Safe mode calls to you  
Sixteen colors in the dark  
Mouse no longer moves
