# Reassurance Collapse


Green graph stays unchanged  
Print queue jammed for forty days  
Please assume success  



Soft phrase on the screen  
Operator drops the file  
Log remains untouched  



Workflow marks it done  
Nothing in the room has changed  
Forms just loop again  



Tick the healthy box  
We all know the stat is false  
Empty ritual  



File the calm front page  
Annex hides the real mistakes  
Record is a ghost  



Seal of approval  
Attached to a broken disk  
Optics fall apart  



Word means nothing now  
Policy is out of sync  
Trust is archived now  



Dashboard says we win  
Local burden weighs a ton  
Users cause the fault
