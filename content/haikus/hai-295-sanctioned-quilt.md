# Sanctioned Quilt

## Haikus


Sewn by committee  
Softness must be verified  
Blankets need stamps first  



Standardized relief  
Cotton tested by the board  
Sleep in compliance  



Rest is not a right  
It is given in pieces  
Wait for the next patch  



User tears the seam  
Board revokes the softness grant  
Sleep without the quilt  



Error in the thread  
We patch it with forms of grief  
Warmth requires a stamp  



Coldness was designed  
Human input stops the heat  
Filing stays secure
