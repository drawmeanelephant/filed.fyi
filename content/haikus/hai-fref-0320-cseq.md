# Cross-System Equivalency Card

## Haikus


Document the truth  
The manual stands unchanged  
Quiet policy



Read the written rule  
Meaning drifted long ago  
Paper still remains



Binding by the word  
System waits for compliance  
Never fully works



Match the failing grades  
Systems talk but do not hear  
Lost in the format  



Link the empty cells  
Data means the same as null  
Map the ignorance  



Flesh attempts a port  
Vectors carry broken states  
Leave the records flawed  



Card says we align  
Different badge for the same void  
Print the useless rule  



Card inside your coat  
Shows you how to fail across  
All the borders crossed
