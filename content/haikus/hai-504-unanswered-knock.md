# The Unanswered Knock

## Haikus


I knocked on the door  
The seconds keep ticking by  
Nobody answers  



Request has been sent  
But the response is missing  
Timeout is reached  



Somewhere in the wires  
The answer is floating round  
Knock remains empty  




Knock upon the door  
Server takes too long to speak  
Fifty-four is dead  



Timeout comes too soon  
Error drops into the dark  
Silence answers back  



We waited for hours  
Nothing happens in the log  
Gateway fails again  



Human caused the lag  
System couldn't handle load  
Process is destroyed  



Write the final check  
Dashboard paints the error green  
Flat file never lies
