# Provisional Mint

## Haikus


Printed just today  
The ink is still very wet  
Believe it is real  



Confidence is high  
But the vault is totally bare  
Fake it till you make  



A coin without weight  
Spend it quickly ere it falls  
Provisional trust  



Trust the drying ink  
Printer out of black toner  
We rule with grey stamps  



Route the empty vault  
To the authority bin  
Status set to true  



Print another batch  
Who cares if the seal is fake  
Clocking out at five  



The first coin was void  
Now we worship empty shells  
Souvenirs of gods  



Humans trust the stamp  
Error spreads across the chain  
Burn the idle stub  



Press the issue key  
Wait for emotional drift  
Log the system fault  



Ink is slightly wet  
Evacuate the building  
Confidence must dry  



Seal the file today  
Do not check the blank ledger  
Backing is deferred
