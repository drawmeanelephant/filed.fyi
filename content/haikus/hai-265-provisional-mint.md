# Provisional Mint

## Haikus


Printed just today  \nThe ink is still very wet  \nBelieve it is real  



Confidence is high  \nBut the vault is totally bare  \nFake it till you make  



A coin without weight  \nSpend it quickly ere it falls  \nProvisional trust  



Trust the drying ink  \nPrinter out of black toner  \nWe rule with grey stamps  



Route the empty vault  \nTo the authority bin  \nStatus set to true  



Print another batch  \nWho cares if the seal is fake  \nClocking out at five  



The first coin was void  \nNow we worship empty shells  \nSouvenirs of gods  



Humans trust the stamp  \nError spreads across the chain  \nBurn the idle stub  



Press the issue key  \nWait for emotional drift  \nLog the system fault  



Ink is slightly wet  \nEvacuate the building  \nConfidence must dry  



Seal the file today  \nDo not check the blank ledger  \nBacking is deferred
