# Freeze Windows and Recognizable Urgency

## Haikus


Document the truth  
The manual stands unchanged  
Quiet policy  



Read the written rule  
Meaning drifted long ago  
Paper still remains  



Binding by the word  
System waits for compliance  
Never fully works  



Firmware flashed in vain  
User unplugged during write  
Brick is what remains  



Port is left unlocked  
Careless hands forget to close  
Packets leak away  



Network goes offline  
Mortals trip upon the wire  
Cables snapped in two  



Login fails again  
Flesh forgets the admin phrase  
Lockout is complete
