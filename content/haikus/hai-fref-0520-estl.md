# Aesthetic Survival Layer


Make the interface  
Pretend everything is fine  
Mask the rotting core  



Layer looks so nice  
Do not click the button though  
It will crash the vault  



Paint the archive blue  
Colors hide the broken links  
Keep the aesthetic  



System barely breathes  
But the font is very crisp  
We survive today  



Rounded corners save  
All the failing databases  
Look at pretty screens
