# Green Band Canonization

## Haikus


Ambiguous state  
Painted over with the green  
Now it is healthy  



Canonization  
We declare it is robust  
Without any proof  



Dashboard aligns well  
With the need for confidence  
Ignore the red lights  



Preserve the feeling  
That the machine is working  
Reclassify doubt  



Green band forever  
If we widen the margins  
We can never fail
