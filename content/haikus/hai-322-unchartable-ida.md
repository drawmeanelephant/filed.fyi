# Unchartable Ida

## Haikus


No field for that pain  
still the hallway remembers  
what the chart forgot  



Blank survey box waits  
not empty, only careful  
around hungry graphs  



The number asked twice  
Ida answered with witness  
and one closed laptop  



Trendline stays calm green  
private notes grow weathered teeth  
under the clean band  



Free text survives where  
dropdowns fail to hold the shape  
of a living bruise  



Quiet interval  
not recovery, maybe  
filing learned to hide  



Anecdote kept warm  
until the metric admits  
its little border  



Graphable mercy  
missed the ungraphable need  
Ida kept both names  



Measurement bows  
when it remembers it is  
not the whole window  



Off chart, not unreal  
the archive keeps a margin  
wide enough for grief  



Field is left so blank  
Graph is fed but still hungry  
We logged the silence  



Pain will not map right  
Update the index of tears  
Format is locked down  



Uncharted despair  
Error states its own soft case  
Form rejects the blood  



Not a clean signal  
Dashboard throws a time-out code  
Grief hides in the null  



In the dropdown box  
There is no option for grief  
Form submits as null  



User typed the pain  
Metric could not parse the text  
Stored as invalid  



Graph is a flat line  
Human error makes a noise  
Silence the alert  



Record stays secure  
Data refuses the blood  
Audit looks so clean  



Input too complex  
Please select from dropdown list  
Pain must be string type  



No data in field  
System logs perfect health state  
Silence saves the chart  



Graph is missing tears  
We have banned unmeasured grief  
Dashboard now complete  



Slow moving burden  
Ruins our clean reporting  
Close the ticket now  



Graph will stay so clean  
Human tears are left unweighed  
File the silence now  



Dashboard turns to green  
Unmeasured pain left behind  
Error code was saved  



Format must not break  
Dropdown box avoids the truth  
Status is complete
