# The Second Domino

## Haikus


I watch the first one  
When it falls I take the rest  
Cascade has begun  



Twelve follow-ups die  
Because one job could not run  
Domino effect  



Tied to the failure  
I only exist to fall  
When the front line drops  




First one falls right down  
Second domino remains  
Waiting for the push  



Cascade is delayed  
System hesitates to crash  
Fear is in the code  



Nothing touches it  
The second piece will not move  
Errors stand up straight  



Push the plastic block  
Watch the database collapse  
Gravity wins out  



Everything falls down  
Record the sequential death  
Flat file loves the end
