# Managed Absence Spine

## Haikus


Document the truth  
The manual stands unchanged  
Quiet policy  



Read the written rule  
Meaning drifted long ago  
Paper still remains  



Binding by the word  
System waits for compliance  
Never fully works  



Map is drawn amiss  
User wanders off the path  
Vector yields to void  



Grid is out of bounds  
Human fails to read the scale  
Coords lost in space  



Routing graph is torn  
Flesh undoes the shortest path  
Dead ends multiply  



Nodes are left unlinked  
Blind eyes miss the junction point  
Travel is denied  



Compass spins around  
Magnet held by clumsy hands  
North is nowhere now
