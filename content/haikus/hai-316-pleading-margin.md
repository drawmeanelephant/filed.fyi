# Pleading Margin

## Haikus


Clean form is printed  
But the tears are in the ink  
Written on the side  



Official lines end  
Desperation needs a space  
Margin holds the truth  



No box for my grief  
So I write it where I can  
Filing stays unchanged  



Box refuses tears  
Human scratches on the side  
Pressure starts to leak  



Clean blank admin space  
Side channels hold all the filth  
Filings stay so clean  



Handwritten mistake  
Scanner does not read the ink  
Silent edge remains  



Margins beg for help  
No authority to read  
Page is put away
