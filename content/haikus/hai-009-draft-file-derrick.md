# Draft File Derrick

## Haikus


Drafts remain unsent  
Tainted with my silent tears  
Never to deploy  



Words left half-written  
Waiting for a final save  
Rotting in the cache  



I hold the lost drafts  
No system wants to admit  
Failure is a file
