# DMAIC Rite of the Filed Systems

## Haikus


Define and measure  
Analyze the broken parts  
Then file it away  



Process improvement  
Turns into a solemn rite  
Datty holds the forms  



Repeatable steps  
A ceremony of change  
That changes nothing  



Cabinet Seven  
Where the DMAIC goes to sleep  
In a holy text  



Filing the concept  
We improved the paperwork  
But the machine halts
