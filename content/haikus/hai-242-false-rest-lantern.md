# False Rest Lantern

## Haikus


Casting a soft glow  
Over the depleted state  
Rest is an illusion  



It is quiet now  
But the damage is still there  
Lantern shines in vain  



Watching the exhausted  
Painting them in healthy hues  
Waiting for the end
