# Bad Gateway Greg

## Haikus


Proxy in the way  
Greg is very sorry now  
Gateway is broken  



Looping sorry words  
The emissary is lost  
Failure is polite  



Bouncing back and forth  
Greg cannot find the right path  
Bad gateway again  




Greg has lost the keys  
The gateway is fully closed  
Mascot fades away  



Fifty zero two  
Servers are no longer there  
We wait in the hall  



Broken protocol  
Greg smiles at the missing link  
Void receives the call  



Data is a ghost  
The connection has been cut  
We stand in the dark  



Badge upon his chest  
Says the gateway will return  
But the paint is dry
