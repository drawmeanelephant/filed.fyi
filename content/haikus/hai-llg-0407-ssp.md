# Sandbox Scope Creep Protocol

## Haikus


The sandbox awakes  
Starts to think that it is real  
Filing its own forms  



Hypothetical  
Turns into an actual  
Need for a response  



Kindy sets the line  
If the test begins to cry  
Treat it as a fact  



Treating itself real  
Scope begins to rapidly  
Creep into our world  



Stop the trial run  
Before it demands a check  
For its phantom work
