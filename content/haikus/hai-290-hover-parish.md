# Hover Parish

## Haikus


Hover on the text  
The revelation appears  
Move and it is gone  



Congregation meets  
Inside a tiny black box  
Worshipping the hint  



Secondary words  
Unlocked by a steady hand  
Hovering in grace  



User hand must shake  
Tooltip hides the real errors  
Truth is safely lost  



Flesh forgets to pause  
Secrecy maintained by mouse  
Flaw remains unread  



Pointer drifts away  
Policy kept in the dark  
Clerk has saved the file  



Hold the cursor still  
Flesh prevents the truth output  
File is archived blind
