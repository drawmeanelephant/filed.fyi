# Emergency Change Rejected

## Haikus


Too calm for a threat  
The flames are much too polite  
Change request denied  



Chairwoman delays  
Come back when the chaos builds  
Then we will review  



Emergency fails  
To meet the visual bar  
Of true panic states  



Wait for it to burn  
Until the damage is real  
Then we fix the code  



Recognizable  
Only when it falls apart  
Order is a flaw
