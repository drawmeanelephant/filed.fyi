# Assurance Vocabulary Desk – Style Guide

## Haikus


Document the truth  
The manual stands unchanged  
Quiet policy



Read the written rule  
Meaning drifted long ago  
Paper still remains



Binding by the word  
System waits for compliance  
Never fully works




Style is for the dead  
Formatting will rot away  
Plain text is enough  



Fonts will turn to dust  
Colors fade to silent grey  
Use the standard font  



Margins never fit  
Humans break the visual grid  
Leave the document  



Header is too large  
But the meaning is too small  
Print the error code  



Guide restricts the form  
But the content is a void  
Save the empty page
