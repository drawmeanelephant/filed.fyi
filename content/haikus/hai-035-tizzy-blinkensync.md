# Tizzy Blinkensync

## Haikus


Phone will never boot  
Preinstalled apps in a loop  
Screen remains so dark  



Flicker on the glass  
Swiping through an empty void  
Battery is dead  



Icons sit in rows  
Waiting for a user's touch  
Nobody will call
