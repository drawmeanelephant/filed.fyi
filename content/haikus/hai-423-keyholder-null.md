# Keyholder Null

## Haikus


Knock upon the door  
I hold the key but no lock  
Environment sealed  



You knocked perfectly  
But the latch refuses you  
Locked out of it all  



Warden holds them tight  
Every door is shut today  
Null is all you get  




Holder has no keys  
The doors are already gone  
Security fails  



We protect the void  
With an absolutely blank  
Key inside the lock  



Master of the null  
Nobody wants to get in  
Empty is the vault  



Safe is fully bare  
We assign a guard to watch  
Silence in the room  



Logic is unlocked  
Hackers find exactly naught  
System is secure
