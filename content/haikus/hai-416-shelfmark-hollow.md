# Shelfmark Hollow

## Haikus


Look upon the shelf  
The index points to nowhere  
Avatar of void  



Only what is gone  
Is allowed to enter here  
Shelfmark keeps it blank  



Investigate it  
We need the space that we lost  
Hollow laughs at us  




Shelfmark is empty  
Book was never on the wood  
Hollow is the space  



Label points to naught  
We catalog the vacuum  
Library of dust  



Read the empty page  
The identifier is blank  
Record is a ghost  



Shelves are falling down  
But the hollow holds them up  
Structure is a lie  



Find the missing tome  
It was never written down  
File it anyway
