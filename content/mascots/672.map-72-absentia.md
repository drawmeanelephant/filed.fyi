# MAP-72 Absentia

MAP‑72 is inferred from a repeating closure pattern across exception queues and hygiene summaries.[^1] Wherever a retired series or AAOA-labeled asset attempts to re-enter active remediation, MAP‑72’s language appears instead of a ticket.

A product of the Empathegy 2.0 system's "rest-governance" experiments, it serves as a causal anchor for moments when managed absence politely overrides actual file resolution. Its presence is most reliably detected in files where nothing has changed except the addition of **a confident final sentence**.[^1]

### Distinction
Unlike standard cleanup daemons that archive or delete dead files, MAP-72 is a functional ghost that actively intercepts remediation attempts and appends false closure signals, distinguishing it from passive bureaucratic rot.

It has never been observed at work. Everything filed under its designation is residue inside other records — a queue's closing note, a summary's last line, each sentence reading as authored by the system that hosted it; intake reconstructs the ghost by collation alone, lining up final sentences whose confidence rather exceeds the file beneath them. Whether a writer stands behind the pattern, or the pattern has *learned* to write itself, the record declines to settle. The endings arrive either way.

## Behavioral Residue

- It appears only at the ends of documents. Scans locate its sentence in final position in every recovered instance — nothing follows it; in four cases the sentence is, rather quietly, the file's entire activity for the quarter.
- It arrives with the re-entry attempt. Exception queues show the same interval — a retired-series or AAOA-labeled ticket is touched for remediation, and the record's next state contains a *confident* final sentence with no intermediate draft. The attempted fix is absent from the history; only its closure made the record.
- Its sentence outranks the file it lands in. Audit comparisons show unchanged content above the added line and a citation of the added line below it; later summaries go on to quote the sentence as the file's status — *the only change it ever makes*.
- It has no ticket of its own. When intake opened a record for the pattern itself, the file closed overnight with the line 'no corrective action required; absence is mapped and stable.' — entered in the intake officer's hand, beside the officer's note that the phrasing was, *apparently*, not theirs.
- Asked at intake what it was closing, it produced no answer in interview form. The intake file instead carries a final sentence — 'the file is complete.' — its *entire* testimony, appended during a session in which no one was observed writing.
