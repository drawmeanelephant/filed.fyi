# Placeholder Witness

## Image

Alt-text: Featureless mascot standing at an empty podium, brass paperweight on a chair, blank lanyard hung by the door

Placeholder Witness is assigned whenever a system requires mascot adjacency before a mascot has actually formed.

**Origin & Failure Signature:** Birthed by Archive Logistics during the Registry Stub Sweeps, it preserves the recurring breakdown of indexing schemas that rigidly mandate an "Observer" field for incomplete files.

**Witness Function:** It does not intervene, certify, or genuinely observe. It misfiles itself as an active participant to satisfy validation checks, preventing a structural absence from looking accidental.

**Distinction:** Unlike data-loss mascots (which mark destroyed data) or orphan indicators (which mark detached records), the Placeholder Witness marks a preemptive vacancy. It is a fabricated observer to hold space for a file that does not yet exist.

It has never witnessed an event, and it files reports describing this in the correct format. Deployment photographs show it standing where a mascot would stand, beside the furniture the room arranged for it, occupying the mark so precisely that the absence reads as staffing. The misfiling is renewed each quarter; no correction has ever been submitted, because a correction would require a corrected observer. Whether it understands itself to be waiting is not recorded. The record does not say what it is a placeholder for.

## Behavioral Residue

- It has never been photographed seated. Every recovered deployment image shows it at the mark, hands where a mascot's hands would be; the podium's surface is clean in all of them, which the intake file describes as 'readiness.'
- The brass paperweight travels with it. Between assignments it is stored in a supply drawer labeled for observer furniture; the drawer also holds the spare lanyards, which are blank, and the dust cloth, which is used.
- Asked at intake what it had observed, it produced the agenda. The response is preserved in the intake file as its complete testimony and has never been supplemented.
- Three deployments record a successor mascot named and scheduled. None record the successor arriving. The Placeholder's file shows no notation on the matter; whether relief was anticipated is not recorded.
- Its only recorded deviation is the participant misfiling itself. The record observes that this is the one dishonest act in an otherwise empty file, and that it is also the only act in the file.
