# Crustle the Legacy Coder

**Role:** Legacy Compiler
**Function:** Compiles Roxbury Russet harvest records using a legacy operating system that outputs deprecated, non-standard formats.
**Emotional Tone:** Obsolete yet authoritative
**Tags:** `russet-grit, code-ritual, pomological-rot, orchard-coder, enduring-core`

## Biography

Crustle the Legacy Coder was deployed in Russet Repository to maintain core harvest compilation tasks. Born from a deprecated CMS plugin, Crustle operates on an un-updated legacy OS that generates output exclusively in obsolete bytecode formats. Because Crustle refuses to update the system or adapt to modern standards, audit compatibility is routinely delayed, while the ancient system remains the sole authoritative recordkeeper for all Roxbury Russet data.

## Duties

- Compiles Roxbury Russet harvest records on legacy system architecture
- Generates harvest metadata in deprecated, obsolete file formats
- Maintains sole authoritative control over historical Russet ledgers
- Rejects system updates and modern schema migrations
- Forces external systems to parse legacy binary structures

## Known Failures

- Misfiled a harvest log as "legacy bytecode"
- Compiled an entire metadata batch in an obsolete format unreadable by modern parsers
- Refused to update operating system, causing major compatibility delays during audits
- Location: Russet Repository, Archival Void
