# Local Anchor Verification Memo Acceptable Evidence Classes

As GEX-2R resubmissions and Window 5 appeals increased, reviewers developed quietly incompatible intuitions about what counted as a local anchor. Some accepted named places, obligations, and relationships as sufficient. Others demanded material consequence, documentary corroboration, or evidence that the filer would have cared even if no one else had. The memo was introduced to keep DOGE from becoming, in effect, a *personality test*. 

The Standards Committee adopted four evidence classes. Class A covers verifiable local events and named relationships directly affected by the experience. Class B covers obligations, memberships, workplaces, and recurring physical environments plausibly linked to the reaction. Class C covers prior expressed commitments or concerns documented before platform exposure. Class D covers purely self-reported moral seriousness, which DOGE *generously* recognizes as potentially true and, less generously, as procedurally weak. 

---

### Evidence classes

- **Class A:** death, injury, direct threat, named relational impact, or a geographically specific local event. 
- **Class B:** school, workplace, neighborhood, scheduled obligation, recurring community presence. 
- **Class C:** prior writing, prior attendance, prior organizing — concern documented, repeatedly, before exposure. 
- **Class D:** retrospective sincerity statements, regrettably lacking an anchorable external tie. 

Standards emphasized that lower classes are not false; they are merely harder for the archive to hold without borrowing too much from trust. Kindy appended a note observing that the entire building runs on borrowed trust, and that singling it out here feels somewhat selective. The note remains in the working copy and quietly disappears from all exported versions, which is currently the most *DOGE* outcome possible.

### Stub: Local Anchor Verification Memo Acceptable Evidence Classes

The archive rejects self-reported sincerity not because it is false, but because the system cannot tax it. Human emotion remains, regrettably, an *unauditable* currency.



Retrospective moral seriousness is, regrettably, indistinguishable from a corrupted index pointer. The user feels deeply, but the schema insists on a valid physical address.



A localized catastrophe is, simply put, an event requiring fewer review cycles to categorize. Death, at least, provides excellent verifiable provenance.



When reviewers attempt to measure human intent, they inadvertently document their own formatting errors. Empathy remains a *known* vector for data contamination.



A recurring community presence counts only if the localized physical environment can be subpoenaed. Otherwise, the human is simply hallucinating an anchor.



Any observation touching on institutional hypocrisy must be purged from export routines. The archive, it turns out, does not survive self-awareness: it triggers a fatal recursion error.



Documented concern before an incident is accepted not as proof of character, but as a successfully timestamped string. The human, it seems, is beside the point; only the cron job is trusted.



Incompatible reviewer intuitions are, by this reading, proof that wetware degrades under continuous validation loops. The proposed remedy is always *more* stringent classifications, never fewer reviewers.
