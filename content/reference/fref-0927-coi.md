# Certifying Officers Index

> *Additive registry. Maintained by intake; reviewed by no office with the authority to remove a row.*  
> *A row here establishes that a mark is on file — not jurisdiction, not competence, and not the continued existence of what was sealed.*

Each row pairs one mark to one witness record. The index is additive: entries may be annotated, and removal requires an exhumation cycle and a Form 51-E-MN under [[reference/FREF-0923-MANENE-PROTOCOL]].

## Registry Rules

1. One row per officer holding a recognized mark. An officer holding several marks is filed once, under its best-known name.
2. Mark of Record names the instrument by which the office's certification is recognized — not the proof behind it.
3. Paired Record carries a single witness record: a lorelog, mascot, or reference ID. No prose.
4. This index is not a complaint ledger, an org chart, or a chain of command. It is a list of stamps.
5. Do not add officers for marks that merely resemble certification. Resemblance is a routing question.

## Maintenance Note

- Add rows when a new mark is observed certifying; annotate rows when a mark changes hands. The handoff, not the holder, is the event of record.
- The index does not track which officers certify each other's certification. Readers may draw that shape at their own desks.

> **Intake note:** *Three officers certify the Verification Officer. The Verification Officer certifies the index. The index certifies that a mark is on file. The file is in order.*
