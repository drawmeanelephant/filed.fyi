# HTTP and Tooling Mascot Generation Residue Removed

**Maintenance ID:** 0.1.00004.fnf-mech-004

**Scope:** content/mascots (fourteen records)

---

## What changed

Removed explicit Sora/image-generation machinery from the HTTP and tooling mascot cohort M-0040 through M-0060 (as listed):

- `M-0040` Pngbert Flatly — Sora prompt sections and preset removed
- `M-0041` Reboota Thrice — Sora prompt sections and preset removed
- `M-0042` Robots Dot Txt — Sora prompt sections and preset removed
- `M-0044` Spooler Gremlin — Sora prompt sections and preset removed
- `M-0045` Strutter Crashley — Sora prompt sections and preset removed
- `M-0046` Svgon The Line — Sora prompt sections and preset removed
- `M-0048` Twiggy Snipsnark — Sora prompt sections and preset removed
- `M-0049` Updatey Delaybot — Sora prompt sections and preset removed
- `M-0050` Yammy McParseface — Sora prompt sections and preset removed
- `M-0051` Zooki Lockjaw — Sora prompt sections and preset removed
- `M-0053` Tabby Fields — Sora preset section removed
- `M-0054` Hammy Navstack — Sora preset section removed
- `M-0057` Zhuzhing Ping — Sora prompt section removed
- `M-0060` Courier Rat — Sora preset section removed

Each removal deleted the `## 🎨 Sora Prompts` / `## Sora Prompts` section (including `Prompt 1` / `Prompt 2` scene-style blocks), the `## 🧪 Sora Preset` / `## Sora Preset` section, and the associated `preset_...` token. The mascots' biographies, addenda, aphorisms, haiku logs, and limerick logs were preserved.

### Structural repair after removal

- In `M-0042` and `M-0044`, the `---` directly below the preset token was part of the residue block's formatting; it was removed with it.
- In `M-0041`, the extra blank lines left between the removed preset block and the Addendum heading were collapsed to the standard single blank line.

## What was deliberately left alone

- No identity changes, graph repair, doctrine rewriting, prose modernization, or general mascot cleanup.
- Technical vocabulary belonging to each mascot's failure signature was preserved: HTTP status behavior (`M-0049`), reboot/triple-restart behavior (`M-0041`), crawler and Robots Exclusion Protocol content (`M-0042`), SVG terminology (`M-0046`), print queue behavior (`M-0044`), YAML parsing (`M-0050`), templating/bracket policing (`M-0048`), lockfile/concurrency content (`M-0051`), spreadsheet/data structure content (`M-0053`), navigation/routing content (`M-0054`), markup-maximalism content (`M-0057`), and courier/recursion content (`M-0060`).
- `## Image` fields that reference a filename or token (e.g., `M-0041`, `M-0046`) were kept; they are canonical content, not generation machinery.
- In `M-0053`, the `## Image` section with the mouse/clipboard description was kept; it is a canonical depiction consistent with other Image sections in the corpus, not a Sora-labeled prompt.
- In `M-0057`, the empty `## 🧼 Slogans` heading (pre-existing) was left in place.
- Sora sections in mascots outside the listed cohort were not touched; this pass is scope-limited by design.
