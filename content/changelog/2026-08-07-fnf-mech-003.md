## What changed

Removed explicit Sora/image-generation machinery from the early mascot cohort M-0025 through M-0037 (excluding M-0032):

- `M-0025` Ami Ghostbyte — Sora prompt sections and preset removed
- `M-0026` Bea Crashwell — Sora prompt sections, preset, and its trailing `---` separator removed
- `M-0027` Comrade Kernelov — Sora prompt sections and preset removed
- `M-0028` Genny Compileheart — Sora prompt sections and preset removed
- `M-0029` Haikool Breeze — Sora prompt sections and preset removed
- `M-0030` Holy DOSwell — Sora prompt sections and preset removed
- `M-0031` Melody Errorflood — Sora prompt sections and preset removed
- `M-0033` Planny F. PipeMD — Sora prompt sections and preset removed
- `M-0034` Sol Burnout — Sora prompt sections and preset removed
- `M-0035` Tizzy Blinkensync — Sora prompt sections and preset removed
- `M-0036` Whistlin Winstinct — Sora prompt sections and preset removed
- `M-0037` Winona Crashington — Sora prompt sections and preset removed

Each removal deleted the `## 🎨 Sora Prompts` section, the `## 🧪 Sora Preset` section, and the associated `preset_...` token. The mascots' biographies, addenda, aphorisms, haiku logs, and limerick logs were preserved.

### Structural repair after removal

- In `M-0030`, `M-0031`, and `M-0033`, the `### Traits` subsection sat inside the deleted `## 🧪 Sora Preset` section. Its content is in-universe behavior, not generation machinery, so it was kept and promoted to a top-level `## Traits` heading to avoid stranding a subsection under the preceding section.
- In `M-0026`, the `---` directly below the preset token was part of the residue block's formatting; it was removed with it.

## What was deliberately left alone

- No identity changes, graph repair, doctrine rewriting, prose modernization, or general mascot cleanup.
- In `M-0027`, the `## 🧰 Mascot Loadout` section (which sits between the prompt and preset blocks) was kept.
- In `M-0037`, the `## 🧠 Known Traits`, `## 🎖️ Office Artifacts`, `## 🕯️ Council Placement`, and `## 🧼 Slogans` sections (which sit between the prompt and preset blocks) were kept.
- In `M-0033`, the `🔗 Reference` block with the official Plan 9 link was kept; it is a factual reference, not generation machinery.
- Odd tags (e.g., `M-0026`, `M-0035`, `M-0036`) were left untouched; none refer exclusively to the deleted generation machinery.
- Sora sections in mascots outside the listed cohort were not touched; this pass is scope-limited by design.
