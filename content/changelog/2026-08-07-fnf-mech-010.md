## What changed

Removed the poetry-generation execution machinery from the nine reference records formerly serving as JULES-POET work orders. Each record was reduced to a short historical-residue stub: the canonical `id` and `parent` were preserved, `status` set to `archived`, tags reduced to `["reference", "historical-residue"]`, and the body replaced with a single factual sentence identifying the record as a retired poetry-restoration work order preserved as historical residue.

Removed from each record:

- processor/JULES-POET assignment framing,
- monitored target coordinate manifests (`hai-*.mdx`, `lim-*.mdx`, `LIM-*.mdx` ephemeral paths),
- system directive/instruction blocks (including `node scripts/audit-poetry-vectors.mjs` invocations and `src/content/docs/reference/fref-0900-poet.mdx` report lookups),
- direct poetry-generation constraints (theme/tone stances, composition and format constraints),
- current-tense execution language,
- the `scratchpad` / `prompt-addendum` tags and the appended verse echoes (identical verse remains in the canonical satellite records under haikus/aphorisms/limericks).
