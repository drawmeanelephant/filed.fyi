# Legacy Themed Mascot Generation Residue Removed (B)

**Maintenance ID:** 0.1.00006.fnf-mech-006
**Date:** 2026-08-07
**Scope:** content/mascots (twelve legacy themed records)

---

## What changed

Removed explicit Sora/image-generation machinery from the legacy themed mascot cohort M-0211 through M-0221 (excluding M-0214) plus M-0260 and M-0275:

- `M-0211` Apex Goldbricker — Sora prompt sections and preset removed
- `M-0212` Jack Hererherald — Sora prompt sections and preset removed
- `M-0213` Ketchup Keeper — truncated Sora prompt section removed (no preset present)
- `M-0215` Guacamole Gardener — truncated Sora prompt section removed (no preset present)
- `M-0216` Corelock the Flavor Warden — Sora prompt sections and preset removed
- `M-0217` Lord Spitzenfile — Sora prompt sections and preset removed
- `M-0218` Crustle the Legacy Coder — Sora prompt sections and preset removed
- `M-0219` Glassy MacCheckface — Sora prompt sections and preset removed
- `M-0220` Bananuity Clause — Sora prompt sections and preset removed
- `M-0221` Agent McCrisp — Sora prompt sections and preset removed
- `M-0260` Sidebar Mercy — Sora prompt sections and preset removed
- `M-0275` Appendix Silk — Sora prompt sections and preset removed

Each removal deleted the `## 🎨 Sora Prompts` section (or the un-emoji'd `## Sora Prompts` variant in M-0260 and M-0275), the `## 🧪 Sora Preset` / `### Sora Preset` section, and the associated `preset_...` token (e.g. `preset_corelock_blackcrisp`, `preset460sidebargrace`). The mascots' biographies, duties, known-failure logs, addenda, aphorisms, haiku logs, limerick logs, and associated-mascot lists were preserved.

### Truncated sections

In `M-0213` and `M-0215` the Sora prompt section was already cut short mid-bullet — a lone `- **Scene:** …` under `### Prompt 1` with no Prompt 2 and no preset. These truncated fragments were removed in full; no preset token existed in either record.

## What was deliberately left alone

- No identity changes, graph repair, doctrine rewriting, prose modernization, or general mascot cleanup.
- The addendum comments, aphorisms, haiku logs, and limerick logs in all twelve records were preserved verbatim, including in-universe references to "compilers" and generation in verse (e.g. the "Tomato Tang Compiler" and "Fresh Zest Compiler" limericks). Those are archival fiction, not generation machinery.
- `M-0214` Sriracha Sentinel was not part of this pass. It sits in the same themed cohort range but was not in the target list; it carries no Sora prompt/preset sections in any case.
- Sora sections in mascots outside the listed cohort were not touched; this pass is scope-limited by design.
- Blank-line padding left directly behind the deleted Sora heading in `M-0211` was collapsed to the standard single blank line. No other whitespace outside the deleted blocks was altered.
