# Cluster Re-Indexing Aphorisms


The cluster is hereby informed that it has always been a cluster. Administrative clarity arrived after usefulness had departed.



Retroactive structural identity: the system declines to choose between versions and treats conflict as a stable feature. Nothing was resolved. The record now looks official.



Any finer distinction between 'when' and 'since when' the cluster exists is left to the drift reports. The form remained intact. The situation did not.




Re-indexing does not find the data, it simply hides it more efficiently.



The index points to the void, and the void complies.



If you search for nothing, the results are always accurate.



Human error is the only truly renewable resource.



The structure is flawless; only the reality is broken.
